# 结构型模式

## 描述：
关注对象之间的组合和关系，旨在解决如何构建灵活且可复用的类和对象结构。

## 分类：
- [适配器模式（Adapter Pattern）](./adapter_pattern)
- [桥接模式（Bridge Pattern）](./bridge_pattern)
- [过滤器模式（Filter、Criteria Pattern）](./filter_pattern)
- [组合模式（Composite Pattern）](./composite_pattern)
- [装饰器模式（Decorator Pattern）](./decorator_pattern)
- [外观模式（Facade Pattern）](./facade_pattern)
- [享元模式（Flyweight Pattern）](./flyweight_pattern)
- 代理模式（Proxy Pattern）
