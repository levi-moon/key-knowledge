# 创建型模式

## 描述：
提供了一种在创建对象的同时隐藏创建逻辑的方式，而不是使用 new 运算符直接实例化对象。这使得程序在判断针对某个给定实例需要创建哪些对象时更加灵活。

## 分类：
- [工厂模式（Factory Pattern）](./factory_pattern)
- [抽象工厂模式（Abstract Factory Pattern）](./abstract_factory_pattern)
- [单例模式（Singleton Pattern）](./singleton_pattern)
- [建造者模式（Builder Pattern）](./builder_pattern)
- [原型模式（Prototype Pattern）](./prototype_pattern)
