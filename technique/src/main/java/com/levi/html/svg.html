path参数

M (Move to)

语法: M x y 或 m dx dy

描述: 将画笔移动到指定的坐标 (x, y)（绝对定位）或相对于当前位置的偏移量 (dx, dy)（相对定位）。

L (Line to)

语法: L x y 或 l dx dy

描述: 从当前位置画一条直线到指定的坐标 (x, y) 或相对于当前位置的偏移量 (dx, dy)。

H (Horizontal line to)

语法: H x 或 h dx

描述: 画一条水平线到指定的 x 坐标或相对于当前 x 坐标的水平偏移量 dx。

V (Vertical line to)

语法: V y 或 v dy

描述: 画一条垂直线到指定的 y 坐标或相对于当前 y 坐标的垂直偏移量 dy。

C (Cubic Bezier curve)

语法: C x1 y1 x2 y2 x y 或 c dx1 dy1 dx2 dy2 dx dy

描述: 使用三次贝塞尔曲线从当前点绘制到 (x, y)。(x1, y1) 和 (x2, y2) 是控制点。

S (Smooth cubic Bezier curve)

语法: S x2 y2 x y 或 s dx2 dy2 dx dy

描述: 与 C 命令类似，但第一个控制点是前一个命令第二个控制点的镜像。如果前面没有 C 或 S 命令，则等同于 M 命令后的 C 命令。

Q (Quadratic Bezier curve)

语法: Q x1 y1 x y 或 q dx1 dy1 dx dy

描述: 使用二次贝塞尔曲线从当前点绘制到 (x, y)。(x1, y1) 是控制点。

T (Smooth quadratic Bezier curve)

语法: T x y 或 t dx dy

描述: 与 Q 命令类似，但控制点是前一个命令控制点的镜像。如果前面没有 Q 或 T 命令，则等同于 M 命令后的 Q 命令。

A (Arc)

语法: A rx ry xAxisRotate largeArcFlag sweepFlag x y 或 a rx ry xAxisRotate largeArcFlag sweepFlag dx dy

描述: 通过椭圆弧绘制到指定的 (x, y)。rx 和 ry 是椭圆的半径，xAxisRotate 是 x 轴旋转角度，largeArcFlag 表示选择大弧还是小弧，sweepFlag 表示弧的方向，dx 和 dy 是相对于当前位置的偏移量。

Z (Close path)

语法: Z 或 z

描述: 关闭当前路径，将画笔移动到起始点。
